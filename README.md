## 📱 Instalação

### Android

1. Baixe o arquivo APK da [página de releases](https://github.com/xcoretv/vizzion_plus/releases/latest)
2. Habilite "Fontes Desconhecidas" nas configurações do seu dispositivo:
   - Vá para **Configurações** → **Segurança** → **Fontes Desconhecidas**
3. Abra o arquivo APK baixado
4. Siga as instruções na tela para instalar

**Nota**: O aplicativo não fornece conteúdo. Você deve ter suas próprias playlists ou credenciais Xtream Codes.

## 🚀 Como Usar

1. Abra o aplicativo Vizzion Plus
2. Configure sua playlist:
   - **M3U/M3U8**: Adicione a URL da sua playlist ou carregue um arquivo local
   - **Xtream Codes**: Insira suas credenciais (URL, usuário e senha)
3. Aproveite seu conteúdo!

## ⚙️ Requisitos

- **iOS**: iOS 12.0 ou superior (em breve)
